# record-converter

# introduction

互相转换鸣潮工具的抽卡记录格式

支持工具:
- [WutheringWavesTool](https://github.com/leck995/WutheringWavesTool)的xlsx表格  
- [wuwatracker](https://github.com/wuwatracker)的json字典  `注意时区选择`
- [WutheringWavesUID](https://github.com/MoonShadow1976/WutheringWavesUID)的json抽卡记录  `结构简单的格式中转站`

*不对库洛的抽卡记录进行修改，只做转换。*

## How to start

```
# 激活虚拟环境（如有）
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 运行程序
python main.py

#注: 放置需要转换的文件到data文件夹
```
